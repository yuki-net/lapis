# Lapis

Lapis は、Rust と GPUI を中心に開発している、ローカル・リモートの開発作業を扱うエディター／ワークスペースです。現在のリポジトリは開発中のプロトタイプであり、ディレクトリ構造や機能の完成度は固定されていません。
