Lapis は現在開発中のプロトタイプです。このサイトでは、実装とリリースで確認できた利用者向けの操作・設定だけを案内します。計画中の機能は、実装済みの保証として扱いません。

## ここから読む

- [はじめに](/guide/getting-started/) — 現在の状況、試し方、情報の探し方
- [GitHub リポジトリ](https://github.com/yuki-net/lapis) — ソースコード、Issue、変更履歴
- [Issues](https://github.com/yuki-net/lapis/issues) — 既知の問題と開発中の作業

## このサイトの方針

- 利用者が観測できる操作・設定・振る舞いだけを掲載します。
- 内部アーキテクチャや実装計画は、利用者向け仕様として掲載しません。
- 未確定の内容は、決定済み・実装済みと誤認させない書き方をします。
