## 現在の状況

- 配布用の安定版はまだ提供していません。インストール手順や対応環境は、リリース時にこのサイトで案内します。
- 実装済みの範囲は日々変わります。最新の状態は GitHub の Issue と PR で確認してください。
- 画面や操作は予告なく変わります。このサイトの記述も、確認できた時点の内容です。

## ソースから確認する

開発中の動作を手元で確認する場合は、リポジトリを取得します。ビルドと起動に必要な環境は、リポジトリ内の開発手順に従ってください。

```sh
git clone https://github.com/yuki-net/lapis.git
cd lapis
```

起動方法や必要なツールは、リポジトリの [README](https://github.com/yuki-net/lapis/blob/develop/README.md) と開発ドキュメントを参照してください。配布物ではないため、環境によってはビルドできない場合があります。

## 情報の探し方

- **使い方・設定** — このサイトのガイド。確認できた操作から順に追加します。
- **不具合・要望** — GitHub の [Issues](https://github.com/yuki-net/lapis/issues)。既存の報告を検索してから起票してください。
- **変更の履歴** — GitHub の [Pull requests](https://github.com/yuki-net/lapis/pulls)。何がいつ変わったかを追えます。

## このサイトの読み方

このサイトは、利用者に見える振る舞いを所有します。内部の設計判断や実装上の制約は掲載せず、リポジトリ内の仕様書に分けて管理しています。そのため、ここに書かれていない機能は「未実装」ではなく「未確認」です。

内容に誤りや古い記述を見つけた場合は、GitHub の Issue で知らせてください。
