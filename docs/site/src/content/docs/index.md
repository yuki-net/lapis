Lapis は Rust と GPUI を中心に開発しているエディター・開発ワークスペースです。

このサイトは利用者に見える操作と振る舞いを案内します。開発途中の機能については、実装・リリースされていると推測せず、確認できた内容だけ記載します。

- [はじめに](/guide/getting-started/) — 現在の状況と情報の探し方
- [GitHub リポジトリ](https://github.com/yuki-net/lapis) — ソースコードと開発の進捗
